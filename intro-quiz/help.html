교사용 화면으로 돌아가기

전주 퀴즈 사용 안내

교실에서 시작하기

  1. 교사용 페이지를 열고 연도·장르·문제 수를 선택합니다.
  2. 문제은행에서 미리듣기를 하고 영상의 음악 시작 시간을 조정합니다. 뮤비에는 대사나 무음 구간이 있을 수 있습니다. 음원 영상으로 교체하려면 ‘설정 → 유튜브에서 음원 찾기’를 사용하세요.
  3. 정답 영상은 원하는 교차편집이나 뮤비 주소를 넣고 별도의 시작 시간을 지정합니다.
  4. 같은 컴퓨터의 디스플레이를 확장 모드로 설정하고 ‘TV 화면 열기’를 누릅니다. 새 창을 TV로 옮긴 뒤 전체 화면으로 전환합니다.
  5. 컴퓨터의 오디오 출력을 TV/HDMI로 선택합니다. 전주 소리는 교사용 창에서, 정답 소리는 TV 창에서 재생됩니다.
  6. 문제를 시작하고 0.5초 → 1초 → 3초 이상 순서로 들려줍니다. 각 단계는 같은 전주 시작 지점에서 재생됩니다. 정답 공개 후 다음 문제로 진행합니다.

유튜브 재생 특성

음원 파일을 추출하거나 내려받지 않고 YouTube 공식 임베드 플레이어를 사용합니다. 광고·버퍼링·탐색 지연·브라우저 스케줄링으로 실제 재생 구간에는 오차가 있습니다. 특히 0.5초 재생은 정밀한 오디오 편집 수준을 보장하지 않습니다.

자동재생이 막히면 플레이어를 직접 클릭해 주세요. 외부 재생이 제한되거나 삭제된 영상은 다른 유튜브 주소로 바꾸세요. 정답 화면에는 ‘유튜브에서 열기’ 링크도 있습니다.

문제은행의 기본 링크는 2026년 11월 24일 검색 결과로 확인한 공식 음원·뮤비·라이브 영상입니다. 개별 영상의 실제 재생 가능 여부 및 전주 시작 지점은 아직 수업 환경에서 검수되지 않았으므로 처음에는 ‘미리듣기 필요’로 표시됩니다.

저장과 이동

문제은행 수정 내용은 현재 브라우저의 로컬 저장소에 보관됩니다. 브라우저 데이터를 지우면 사라질 수 있으므로 ‘내보내기’로 JSON 파일을 보관하세요. 다른 컴퓨터에서는 ‘가져오기’로 목록을 합칠 수 있습니다. 같은 곡 ID는 가져온 내용으로 갱신됩니다. 진행 중 게임은 새 게임을 시작할 때 가져온 목록을 반영합니다.

TV 동기화는 같은 브라우저·같은 컴퓨터에서 열린 창 사이에서 작동합니다. 다른 컴퓨터나 TV 자체 브라우저와의 원격 동기화는 지원하지 않습니다.

로컬 실행

저장소 폴더에서 python3 -m http.server 8000을 실행한 뒤 http://localhost:8000/intro-quiz/로 접속하세요. HTML 파일을 직접 여는 file:// 방식은 유튜브 재생과 창 동기화를 지원하지 않습니다. 기존 아나 사이트와 함께 정적 호스팅할 수 있습니다.
